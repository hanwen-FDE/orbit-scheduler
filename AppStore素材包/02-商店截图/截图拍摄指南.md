# Orbit 商店截图拍摄指南（6.9 英寸一套，共 8 张）

> 目标：8 张真机截屏 → 放入「原始截图」→ 运行 `make_screenshots.py` → 「成品」直接上传 App Store Connect。
> iPhone 专用 App 只需 **6.9 英寸（1320×2868）一套**，ASC 会自动派生其他尺寸。

## 一、拍摄前准备（10 分钟）

1. **设备**：最好用 iPhone 16 Pro Max（截屏即 1320×2868，无需缩放）。
   其他全面屏 iPhone 也可——脚本会把任意分辨率的截屏等比放进 1320×2868 画布。
2. **造测试数据**：系统日历新建一个「测试」日历（选一个醒目颜色），录入：
   - 09:00–09:30 晨会（工作）
   - 10:00–11:30 门诊三楼课题会（循环：每周三）
   - 14:00–15:00 瑜伽课
   - 18:30 晚餐（提醒：提前 30 分钟）
   - 一条全天事件：家人生日 🎂
3. **清场**：通知中心清空、后台无红点、无低电量黄色图标；深色/浅色模式全程统一（建议浅色，与截图模板白底一致）。
4. **配置好 AI Key**：左上角头像 → AI 识别 → 填入可用的智谱 Key 并测试连接成功（否则卡片生成不出来）。
5. **隐私红线**：截图中不得出现真实人名、电话、地址、就诊信息——全部用测试数据。

## 二、逐张拍摄脚本

截屏方法：同时按**侧边键 + 音量上键**，松开即存相册。

| 编号 | 画面 | 操作路径 | 画面必须出现 |
|---|---|---|---|
| 01 | 对话页闭环 | 对话页输入「下周三下午4点在门诊三楼开课题会」→ 发送 → 等卡片生成并写入日历 | 用户消息、AI 日程卡片、成功写入提示 |
| 02 | 图片批量识别 | 准备一张课程表/排班表截图 → 对话页点 📷 选图发送 → 多张日程卡生成 | 图片消息 + 多张日程卡片 |
| 03 | 卡片编辑 | 点开任一日程卡片进入编辑页 | 循环规则选择、提醒档位、时间选择器 |
| 04 | 今天页 | 切到「今天」页（已有多条测试日程） | 时间轴、多日程、全天事件 |
| 05 | 冲突建议 | 先在系统日历造一个 16:00–17:00 的事件，再让 Orbit 识别一个 15:30–16:30 的日程 | 冲突提示 + 建议空档卡片 |
| 06 | 语音输入 | 长按麦克风按钮说话（转写中） | 波形/转写文字、松手即识别的界面 |
| 07 | 晨间简报 | 打开 App 触发晨间简报（天气需真机 entitlement 生效；无天气数据则只拍日程+问候部分，**不要伪造天气**） | 今日日程列表、问候语 |
| 08 | 小组件 + 图标 | 桌面添加 Orbit 快速记录小组件 → 主屏截屏一张；再在 App 内切换 6 色图标各截一张（拼接可选） | 桌面小组件（含 Orbit 图标） |

## 三、合成与上传

1. 截屏 AirDrop / 微信传回电脑，按编号放入本目录「原始截图」：`01.png` … `08.png`
2. 运行：
   ```
   python make_screenshots.py
   ```
3. 打开「成品」逐张检查：文字清晰、画面与文案相符、无隐私信息
4. ASC → 版本页 → 「App 预览和屏幕快照」→ 6.9 英寸栏 → 按顺序上传 `01.png`–`08.png`（首图决定转化率，务必检查）

## 四、改文案

顶部文案条的文字在 `make_screenshots.py` 的 `SHOTS` 列表里改，改完重跑脚本即可。注意：**文案必须与画面内容一致**（App Review 2.3.1 禁止误导性截图）。
