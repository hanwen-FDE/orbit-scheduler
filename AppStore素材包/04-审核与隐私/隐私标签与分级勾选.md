# App 隐私标签 + 年龄分级 + 其他 ASC 勾选项对照表

> 填写位置：App Store Connect → 左侧「App 隐私」「年龄分级」；版本页「价格与销售范围」「出口合规」等。
> 原则：如实勾选，与 `PrivacyInfo.xcprivacy`、代码行为、隐私政策（05-网站页面/privacy.html）三方一致。

## 1. App 隐私（数据收集）

问题「你的 App 是否收集数据？」→ **是**，然后勾：

| 数据类型 | 是否收集 | 详情 |
|---|---|---|
| 位置 → 粗略位置 | **是** | 用途：App 功能（晨间简报本地天气）；不与身份关联；不用于追踪；不用于广告 |
| 账户标识（用户名） | **是** | 用途：账户管理与 App 功能；与身份关联；不用于追踪 |
| 购买记录（积分包交易） | **是** | 用途：购买与积分发放；与身份关联；不用于追踪 |
| 其他用户内容（日程文本/语音转写/图片） | **是** | 用途：云端 AI 识别；经 Orbit 后端与受限模型网关处理；按正式后端行为确认关联性；不用于追踪 |
| 日历 / 提醒事项 / 照片 / 麦克风 | **否** | 不离开设备，按 Apple 定义不算"收集" |
| 标识符 / 使用数据 / 诊断 | **否** | 无统计 SDK、无广告 |

## 2. 年龄分级（内容描述）

全部选「无 / 否」：
- 卡通暴力：无；真实暴力：无；色情裸露：无……（逐项"无"）
- 不含用户生成内容（聊天对象是 AI，对话不公开、无 UGC 社区）→ 如实答"否"
- 不含赌博、竞赛、抽奖
- **结果：4+**

## 3. 出口合规

- 是否使用加密？→ 是，但**仅使用 Apple 系统内置的标准 HTTPS**（ITSAppUsesNonExemptEncryption = NO 已在 Info.plist 声明）→ 按提示选择免除，每版无需额外文件

## 4. 广告标识

- 是否面向儿童定向投放 / 是否使用广告标识符？→ **否**（无广告、无 IDFA）
