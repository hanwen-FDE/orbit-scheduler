## 你还剩 3 件事（都无法由 AI 代替）

1. **拍截图**（约 30 分钟）：按 `02-商店截图/截图拍摄指南.md` 用 iPhone 16 Pro Max 截 8 张屏 → 放入「原始截图」→ 双击或命令行运行 `python make_screenshots.py` → 检查「成品」→ 上传 ASC。
2. **部署网站**（约 10 分钟）：把 `05-网站页面/` 三页传到你的域名（指南有三 种方式，GitHub Pages 最快），拿到 https URL 后回填 ASC 隐私政策/支持/营销 URL。
3. **创建审核测试账号**：在 Orbit 正式后端创建独立账号并预置积分；仅将真实凭证填进 App Store Connect 审核备注，绝不提交 Git 仓库。

## 提交流程速记（详见仓库 APPSTORE_RELEASE_PLAN.md §7）

1. Xcode Archive（正式签名 com.itransstudio.orbit）→ 上传构建
2. ASC 选构建 → 按上表补齐素材 → TestFlight 内部自测一遍
3. Add for Review → Submit for Review（建议手动发布，首图首描述再核一遍）
