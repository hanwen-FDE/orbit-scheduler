二、总原则：最小化处理、不做追踪

Orbit 不包含广告、统计分析或第三方追踪 SDK。日程、提醒事项和本地聊天数据优先保存在你的 iPhone；使用 Orbit 云端 AI 时，必要的账户、交易和识别请求会由 Orbit 服务处理，以完成登录、积分和模型调用。

三、App 使用的系统权限及用途

权限用途
日历（完全访问/写入）把你确认的日程写入系统日历；在"今天"页展示与编辑已有日程；检测时间冲突。
提醒事项在你主动选择"同步到提醒事项"时，把日程或循环习惯写入系统提醒事项。
麦克风 与 语音识别仅在你按下语音按钮时录音并转写为文字用于识别日程；录音不保存、不上传。
相册 / 相机仅在你主动选择图片或拍照时读取所选图片（如课程表、会议通知截图），用于识别其中的日程。
位置（使用期间）仅当你开启"晨间天气"时，用粗略位置获取当地天气（数据由 Apple Weather 提供）；位置信息不上传给任何第三方，也不用于追踪。

四、AI 处理与第三方服务（重要）

Orbit 默认采用"账户 + 云端积分"模式：AI 识别由 Orbit 的受限服务端和模型网关提供。高级用户也可选择"自带 Key"（BYOK）路径，使用自己配置的大模型服务商。

  • 云端模式会处理用户名、密码哈希、登录令牌、积分余额、购买交易信息，以及你主动提交的文字、语音转写文字或图片，以提供识别服务；
  • 模型供应商主密钥只保存于 Orbit 服务端，不会写入 App；
  • 当你主动提交识别内容时，内容会经 Orbit 服务发送至受限模型网关；
  • 若启用高级 BYOK，用户自己的 API Key 仅保存在 iPhone 系统钥匙串（Keychain）中；你可以随时在设置中更换或删除它。
默认情况下登录 Orbit 即可使用云端 AI 积分服务；高级 BYOK 为可选功能，不是普通用户的必经步骤。

五、本地存储与删除

  • 聊天记录、日程卡片、通知记录保存在本机应用目录；偏好设置保存在系统偏好（UserDefaults）；登录令牌和高级 BYOK API Key 保存在钥匙串。
  • 卸载 Orbit 即彻底删除上述全部本地数据，无需额外操作。
  • 单条数据可在 App 内直接删除对应日程或清空对话。

六、儿童隐私

Orbit 在 App Store 的分级为 4+，不面向儿童设计，也不 knowingly 收集任何儿童的个人信息。

七、政策变更

如政策发生变更，我们会更新本页面的"最后更新"日期。重大变更将通过 App 内提示或本页公告告知。

八、英文概要（English Summary）

Orbit is an iOS app developed by an individual developer. It contains no ads, analytics, or tracking SDKs. Schedules, reminders, and local chat data remain on your device. The default Orbit account and cloud-points service processes the account identifier, password hash, transaction and balance records, plus the text, voice transcript, or image you actively submit for AI recognition; the request is routed through Orbit's restricted service to an AI gateway. Tokens are stored in the device Keychain. An optional advanced BYOK path stores your personal API key only in the Keychain. With permission, Orbit reads/writes the system calendar and uses speech, camera/photo picker, and coarse location only for the requested feature. Contact: service.orbit@iChatStudio.com.
