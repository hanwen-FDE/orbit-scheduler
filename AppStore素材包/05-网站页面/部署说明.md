# 网站三页部署说明（隐私政策 / 支持页 / 产品主页）

> 本文件夹是 `website/` 目录的副本（源文件如有修改，以仓库 `website/` 为准并重新同步）。
> 提审前**必须**让 `privacy.html` 通过一个可公开访问的 https URL 访问（App Store Connect 要填）。
> 三个页面为零依赖静态 HTML。支持邮箱统一为 `service.orbit@iChatStudio.com`；上线前确认该邮箱可收信，并将三个页面一同部署。

| 文件 | 用途 | App Store Connect 对应字段 |
|---|---|---|
| `privacy.html` | 隐私政策（中英双语） | App 信息 → 隐私政策 URL（**提审必填**） |
| `support.html` | 帮助与支持 FAQ | App 信息 → 支持 URL（**提审必填**） |
| `index.html` | 产品主页 | App 信息 → 营销 URL（可选，建议填） |

三个页面互相用相对链接引用，放同一目录即可；部署在根目录或子目录（如 `https://<你的域名>/orbit/`）都能正常跳转。

## 上线方式（三选一）

### 方式 A：已有云服务器（nginx / 宝塔 / 静态目录）——最快

```bash
scp index.html privacy.html support.html user@你的服务器:/var/www/orbit/
# nginx 配置让 https://<你的域名>/orbit/ 指向该目录
```

### 方式 B：云厂商对象存储静态托管（无服务器也能上）

1. 阿里云 OSS / 腾讯云 COS 创建 Bucket（公共读）
2. 上传 3 个文件
3. 绑定域名（首次需添加 CNAME）
4. 开启 HTTPS（云厂商免费证书）——**ASC 的 URL 必须 https**

### 方式 C：GitHub Pages（免费，5 分钟）

1. `website/` 目录推到仓库
2. Settings → Pages → Source 选 `main` 分支
3. 得到 `https://hanwen-FDE.github.io/orbit-scheduler/privacy.html` 等
4. （可选）后绑自定义域名

## 部署后自测清单

- [ ] 手机流量（非 Wi-Fi）打开隐私政策 URL 能显示
- [ ] URL 是 https 且证书有效
- [ ] 页面无【待填】字样残留（Ctrl+F 搜索"待填"）
- [ ] 三个页面互跳正常
- [ ] 把三个 URL 回填到 `04-审核与隐私/隐私标签与分级勾选.md` §6 和 ASC
