## 1. App 名称（≤30 字符）✅ 已定稿 2026-09-14

**`Orbit`**（裸品牌名，5 字符）

- **命名体系（用户拍板）**：商店标题只用 `Orbit`；中文语境统一称"轨道"；品类定位"效率·日程助手"由副标题与关键词承载
- **可用性**：中国区/美区苹果接口检索均无 trackName 恰为 "Orbit" 的现有 App（最近似为中国区"Orbit（轨迹）"，不同名不同词）；最终以 ASC 创建 App 时的实时校验为准
- **备案名**：`Orbit`（与商店名逐字一致；工信部接受英文 App 名，如 Notion/Uber 均以英文名备案）
- **ASO 取舍提示**：裸名不含品类词，搜索权重靠副标题（含"日历"）与关键词字段（已含 日程/日历/提醒 等）补足；竞品均把品类词放名称里，这是有意的品牌优先取舍
- **类别**：效率（主分类）；中文宣传语境用"效率日程助手"

## 4. 描述 Description（≤4000 字符）✅ 已备好

```
Orbit 轨道——把每句话写进日历。

一句话、一段语音、一张课程表截图，AI 识别后生成可核对的日程卡片，并由你确认写入 iPhone 系统日历。Orbit 不另造一套日历：已写入的日程始终属于你的系统日历。

【三种输入，怎么方便怎么来】
• 打字："下周三下午4点在门诊三楼开课题会"
• 语音：按住说话，实时转写，松手即识别
• 图片：拍下课程表、排班表、会议通知，逐条识别批量建

【为什么写入系统日历】
识别出的日程写入苹果自带日历——Siri、桌面小组件、Apple Watch、iCloud 同步全部通用。卸载 Orbit，已写入的日程原样保留。

【AI 识别，先核对再写入】
自然语言变成可编辑的日程卡片：时间、地点、循环规则、提前提醒，一目了然。多行日程一次粘贴，逐项生成。

【循环与提醒】
每周例会、工作日上课、每月复诊都支持；提醒可选准时到提前 1 天。

【冲突建议，绝不擅动】
与已有日程冲突时，Orbit 给出可采用的空档建议，由你决定，绝不私自挪动你的安排。

【晨间简报】
今天安排 + 本地天气（Apple Weather 提供）+ 一句问候，可设每天定时通知。

【快速入口】
桌面小组件一键记录；快捷指令支持"快速记录日程""查看今日日程"。

【隐私与账号】
• 不含广告与任何追踪/统计 SDK
• 注册登录（用户名 + 密码）后使用 Orbit 云端 AI 识别，按积分计费；积分仅在本 App 内使用，可在积分商店充值（消耗型项目）
• 登录令牌与对话令牌仅存本机钥匙串（Keychain）
• 高级用户可在「设置 → 高级」改用自己的 API Key（智谱 GLM / OpenAI / 任意 OpenAI 兼容接口）
• 卸载即删除本机全部数据

【要求】
iPhone，iOS 15 或更新版本。默认使用 Orbit 云端识别（按积分计费）；也可自备大模型 API Key（推荐智谱 open.bigmodel.cn，注册即可创建）。

遇到问题？请通过 App 内设置或支持页联系我们：service.orbit@iChatStudio.com。
```

## 9. App 隐私标签勾选对照（ASC → App 隐私）

按"从你的 App 收集了哪些数据"作答（如实勾选，与隐私政策一致）：

| 数据类型 | 是否收集 | 详情 |
|---|---|---|
| 位置-粗略 | **是** | 用途：App 功能；不与身份关联；不用于追踪；不用于广告 |
| 账户标识（用户名） | **是** | 用途：账户管理与 App 功能；与身份关联；不用于追踪 |
| 购买记录（积分包交易） | **是** | 用途：购买与积分发放；与身份关联；不用于追踪 |
| 其他用户内容（日程文本/语音转写/图片内容） | **是** | 用途：云端 AI 识别；通过 Orbit 后端与受限模型网关处理；按实际后端行为确认是否与身份关联；不用于追踪 |
| 日历 / 提醒事项 / 照片 / 麦克风 | **否**（不离开设备，按 Apple 定义不算"收集"） | 勾选界面里如实回答"否" |
| 标识符 / 使用数据 / 诊断 | 否 | 无统计 SDK |
