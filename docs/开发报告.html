1 · 项目概览

1.1 需求

iPhone 15 Pro（iOS 26）上的日程助手：支持语音 / 图片 / 文字三种输入，AI 自动识别为结构化日程，写入手机系统日历；支持多家大模型（保留扩展接口）。

1.2 成品（Orbit v2.1）功能清单

模块功能
聊天主界面消息流交互：用户消息气泡（文字/图片缩略/语音转写）→ 助手回复 + 日程卡片
输入方式底部输入栏：＋（照片/相机）｜文字框｜🎤 语音（点击录音、实时转写、自动发送）
AI 识别多 LLM 统一接口：智谱 GLM（默认，多模态）/ OpenAI / 任意 OpenAI 兼容端点；新增服务商只需继承一个基类
批量识别多行日程逐项识别（每行一项、逐项出卡片写入日历）；整场会议（名称+起止时间）单项录入
日程卡片emoji+标题+日期+时间；提醒开关 + 提醒时长（准时/5/15/30/60/120分钟/1天）；"修改日程"切换日历；点卡片编辑/删除
自动写日历识别成功自动写入默认日历（EventKit 完全访问，兼容"仅写入"降级）
日程页主页右上角"日程"：按时间排序列表，点击修改、左滑删除（同步删日历事件）
侧边抽屉6 套 App 图标切换；API 配置+连接测试；默认日历/默认提醒时长；使用说明
数据聊天记录 JSON 持久化，重启可查；设置存 UserDefaults

2 · iOS 开发前置条件（先读）

为什么这一章最重要：今天实际排障中，多数时间浪费在"没人提前讲清条件"上——开发者模式默认隐藏、免费 Apple ID 的密码规则、Windows 无法编译 iOS 等。以下条件清单在动手前就应确认。

2.1 硬性条件表

条件说明今天是否踩坑
代码编写任何平台（Windows 也行），本质是写 Swift 源码 + Xcode 工程文件否
编译只能在 macOS + Xcode（iOS SDK 专属）。Windows 没有任何官方模拟器/编译器。替代：GitHub Actions 免费 macOS 云构建（本方案）、云 Mac、借 Mac是：一开始假设本机可模拟，实际 preflight 直接失败
GitHub 账号用于云构建（公开仓库 macOS runner 完全免费；私有仓库按 10 倍分钟计费）是：git 不走系统代理推送失败，需配 http.proxy=127.0.0.1:7897
Apple ID免费 Apple ID 即可，无需 688 元/年开发者账号；但免费签名 7 天过期、每 7 天重签是：以为需要开发者账号/协议，实际都不需要
开发者模式iOS 16+ 手机安装侧载 App 必须开启；该开关默认隐藏，需 iMazing（Windows 可用）触发显示是（最大坑）：Sideloadly 报 "Invalid file"，根因就是它
签名工具Sideloadly v0.60+（支持 iOS 26）；爱思助手在申请证书环节失败，Sideloadly 可用是：爱思 token 报错，弃用
App 权限描述Info.plist 必须声明每个权限的用途描述（日历/相机/麦克风/语音/相册），漏一个＝运行时崩溃或静默失败是：日历静默失败、相机闪退，两次都是漏键

2.2 费用

全程 0 元：GitHub Actions 公开仓库免费、免费 Apple ID 签名、iMazing/Sideloadly 基础功能免费。唯一代价是每 7 天连电脑重签一次。要消除 7 天限制：Apple Developer Program 688 元/年（可走 TestFlight，无需开发者模式）。

3 · 无 Mac 的五种 iOS 开发路径

路径成本优点缺点适合
① GitHub Actions 云构建 + Sideloadly 侧载
（本项目采用）		0 元日常只需浏览器+数据线；全自动构建流水线；改代码→push→下载 IPA→重装7 天重签；无法断点调试；模拟器测试要配合 Appetize功能开发、自用分发
② Appetize.io 网页模拟免费额度（约 100 分钟/月）浏览器直接跑编译好的 .app，无需手机无麦克风/相机/推送；性能一般快速验证 UI 逻辑
③ 云 Mac（MacinCloud / MacStadium 等）约 $1/小时起完整 Xcode：模拟器、断点调试、真机调试一步到位要付费；网络延迟影响体验认真持续开发
④ 借/买 Mac人情 / 自购体验最佳，Xcode 一次连接即可显示开发者模式开关依赖他人；Mac 不便宜长期开发者
⑤ 付费开发者 + TestFlight688 元/年签名一年有效；TestFlight 安装不需要开发者模式；可分发给别人年费；仍需一台 Mac 上传构建（可用①的 CI 产出再上传）正式/多人使用
组合建议：个人自用＝①+②；决定长期投入＝③或④；要给同事装＝⑤。

5 · 踩坑记录（12 坑全档）

#现象根因解法
1Windows 上想跑 iOS 模拟器iOS 模拟器 macOS 专属GitHub Actions 云构建 + Appetize/Sideloadly
2Sideloadly 安装报 CFBundleIdentifier手写 Info.plist 缺 BundleID 等必需字段，且关闭了自动生成GENERATE_INFOPLIST_FILE = YES 合并权限描述
3git push 连不上 GitHub系统走 Clash 代理（7897），git 默认不读系统代理git -c http.proxy=http://127.0.0.1:7897 push（Clash 开着时）
4developer.apple.com 显示 302 / 转圈代理退出后直连不稳；未登录先进开发者站被重定向先登 appleid.apple.com 再进开发者站；必要时开代理
5爱思助手"Get Xcode token"失败工具实现兼容性（对手机号 Apple ID 尤甚）弃用，换 Sideloadly
6Sideloadly 登录 -20101两步验证账号密码形态错误见坑 9
7Sideloadly 登录 -22406免费 Apple ID 用了 App 专用密码见坑 9
8Sideloadly "Invalid file"iOS 16+ 开发者模式未开启（开关默认隐藏，连 Sideloadly 自己都触发不出来）iMazing 3.4+（Windows）"启用开发者模式" → 手机设置里开启并重启
9密码到底填哪个苹果规则：App 专用密码只对付费开发者账号有效；免费账号必须 Apple ID 主密码手机号 ID + 主密码（弹验证码就输手机上的码）
10添加日历无弹窗、提示无可用日历缺 iOS 17+ 新权限键 NSCalendarsFullAccessUsageDescription 等补两组日历权限键；申请完全访问、仅写入时回退默认日历
11助手回复整块黑框无文字SwiftUI .background(Shape) 未指定填充色 → 默认前景色填充（黑底黑字）.background(shape.fill(Color(.secondarySystemBackground)))，用户气泡 fill(.blue)
12点相机闪退缺 NSCameraUsageDescription，iOS 直接杀进程Info.plist 补键，首次使用弹权限询问
规律总结：权限键要一次配全（日历/相机/麦克风/语音/相册）；免费侧载三件套= 开发者模式 + 主密码 + Sideloadly；报错先查权限，再查路径，再查网络。

6 · 安装速查卡（新手机/重装/7天重签通用）

1
开启开发者模式：电脑装 iMazing 3.4+（imazing.com）→ iPhone 连线 → 找"启用开发者模式"点执行 → 手机 设置 → 隐私与安全性 → 开发者模式（拉到底）→ 打开 → 输锁屏密码 → 重启手机。（只需一次，已开过的手机跳过）
2
下载 IPA：github.com/hanwen-FDE/orbit-scheduler → Actions → 最新绿勾运行 → Artifacts → 下载 ScheduleAssistant-ipa → 解压出 ScheduleAssistant.ipa，放到纯英文路径（如 D:\ipa\）。
3
Sideloadly 安装：sideloadly.io 装 v0.60+ → iPhone 连线（手机点"信任"）→ 拖入 IPA → Apple Account 填手机号 ID（8613…）→ 密码填 Apple ID 主密码（不是 App 专用密码！弹出验证码就输 iPhone 上显示的 6 位码）→ Start。
4
信任证书：手机 设置 → 通用 → VPN与设备管理 → 点你的 Apple ID → 信任 → 打开 Orbit。
5
每 7 天重签：签名到期 App 打不开时，重复第 3 步（连线 → Sideloadly → Start）即可，聊天记录和日程数据不丢。改了代码就先做第 2 步换新 IPA。
常见报错对照：-20101/-22406＝密码形态错（用主密码）；Invalid file＝开发者模式没开（做第 1 步）；连不上 GitHub＝Clash 开着但 git 没走代理（本仓库已配好，Clash 必须处于开启状态推送）。

7 · 日常维护手册

7.1 改功能 / 修 bug 的标准流程

1. 修改代码（本机 Sources/ 下的 Swift 文件）
2. git add -A && git commit -m "改动说明"
3. git push        （需要 Clash 开着）
4. 等 GitHub Actions 约 1 分钟构建（绿勾=成功，红叉=看日志发我）
5. 下载新 ScheduleAssistant-ipa → 解压覆盖 D:\ipa\
6. Sideloadly 重装（第 6 章第 3 步）

7.2 数据说明

聊天记录与日程快照存于 App 沙盒（orbit-chat.json）；日程本体在系统日历（iCloud 同步）。卸载 App 会清聊天记录，但日历里的日程保留（可在系统日历或 Orbit 重装后通过"日程"页关联的卡片管理）。API Key 存于 UserDefaults，重装覆盖不丢。
